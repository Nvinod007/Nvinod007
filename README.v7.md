## Recently shipped (and why)

### ExecLens — see the JavaScript event loop

Async bugs in React Native drove me crazy. Stack traces tell you *where*; they rarely show *when* microtasks and macrotasks interleave. I built [ExecLens](https://js-exec-lens.vercel.app/) as a step-by-step visualizer — click through execution like a debugger for the event loop.

→ [Live](https://js-exec-lens.vercel.app/) · [Code](https://github.com/Nvinod007/exec-lens)

### Sprint Poker — planning without friction

Sprint planning kept breaking flow: another login, another tab, another tool. I built [Sprint Poker](https://sprintpoker.vercel.app/) so my team opens **one link** — no accounts, no setup. Zero-login real-time voting, because the best tool is the one people actually use.

→ [Live](https://sprintpoker.vercel.app/) · [Code](https://github.com/Nvinod007/sprint-poker)

### CodeNest — one repo to grow in

Scattered one-off repos weren't scaling with how I work. [CodeNest](https://github.com/Nvinod007/code-nest) is an **Nx monorepo** — portfolio, apps, and shared UI/libs in one place. The portfolio at [vinodkumar-flame.vercel.app](https://vinodkumar-flame.vercel.app/) lives inside it.

→ [Live](https://vinodkumar-flame.vercel.app/) · [Code](https://github.com/Nvinod007/code-nest)
